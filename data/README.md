# Datos locales

- `raw/`: archivos originales NASA sin modificar.
- `processed/`: datos transformados y series normalizadas.
- `cache/`: archivos temporales y recuperables.

El contenido de estos directorios se excluye de Git. FUL-101 conserva localmente la respuesta original de NASA POWER (T2M mensual, Wagga Wagga); no se han descargado los productos MERRA-2, GPM IMERG ni GLDAS previstos para el MVP.
