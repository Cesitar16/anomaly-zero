# Decisiones del proyecto

## Confirmadas

- Monorepositorio para frontend, API e investigación.
- React + TypeScript + Vite; Python 3.12 + FastAPI; uv para dependencias Python.
- Región candidata: cuenca Murray–Darling, Australia.
- Período base candidato: 2005–2024.
- Variables iniciales: temperatura del aire, precipitación y humedad del suelo.

## Pendientes

- Métodos estadísticos definitivos.
- API de extracción validada.
- Contratos frontend/backend.
- Librerías geoespaciales.
- Base de datos y hosting.
- Reglas de trabajo Git y GitHub.
